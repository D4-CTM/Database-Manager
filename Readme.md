# Database Manager Tool

> [!IMPORTANT]
> To get this project working locally you would need to have installed
> [libclntsh](https://www.oracle.com/database/technologies/instant-client/linux-x86-64-downloads.html) in your machine.

## Tech stack

Primary Languages:
- Golang
- Typescript
- Html

Dependencies:
* Godror
* Gin
* Vue

Tools:
+ Bun
+ Docker
+ Bootstrap
+ libclntsh 23
